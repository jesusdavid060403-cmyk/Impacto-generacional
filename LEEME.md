# Impacto Generacional
1. Supabase: crea proyecto → SQL Editor → pega `schema.sql`. Desactiva registros públicos y crea tu usuario admin (Authentication > Users).
2. Edita `config.js` con tu URL y anon key (la anon key es pública; la seguridad está en las políticas RLS).
3. Pon tu video en `assets/video.mp4`, fotos en `assets/` y lístalas en `GALLERY`. Opcional: `assets/AmsterdamFour.woff2`.
4. Sube la carpeta a Vercel/Netlify/GitHub Pages. QR → `https://tu-sitio/?src=qr`. Panel: `/admin.html`.
